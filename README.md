<h1 align="center">📚 ArticlesKMP</h1>


🚀 A beginner-friendly **Kotlin Multiplatform (KMP)** project to explore cross-platform development by building a simple articles app for **Android and iOS**.

## 🎯 Project Goals

- 🧩 Learn the fundamentals of Kotlin Multiplatform.
- 🔄 Explore code sharing across Android and iOS.
- ⚙️ Understand shared business logic and platform-specific implementations.
- 📱 Build a simple articles app while learning KMP concepts.
- 🌱 Gradually explore cross-platform development best practices.

## 🛠️ Tech Stack

- 💙 Kotlin
- 🌍 Kotlin Multiplatform (KMP)
- 🤖 Android
- 🍎 iOS

## 📖 Learning Journey

This repository serves as a hands-on learning space to understand KMP concepts, experiment with implementations, and improve cross-platform development skills step by step.
